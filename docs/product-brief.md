# GHOST Product Brief

## Product Name

GHOST

## Tagline

Secure Personal AI Workflow Coordinator

## Product Type

Premium macOS desktop application.

## Core Purpose

GHOST helps coordinate personal software, cybersecurity, networking, and portfolio workflows in a focused local-first desktop app.

## Early MVP Scope

The first MVP focuses on:

- Desktop app shell
- Workflow Execution screen
- Project/session context display
- Static workflow steps
- Manual approval state
- No real AI automation yet
- No unsafe terminal execution
